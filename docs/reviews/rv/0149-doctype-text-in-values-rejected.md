# RV-149 🟢 値の中（CDATA・コメント）に "<!DOCTYPE" という文字列がある応答も、読めない応答にする

- 重要度: 🟢 ／ 観点: API 忠実性
- 状態: wontfix

## 概要

DOCTYPE の検出は、応答の文書全体から `<!DOCTYPE` を探す。CDATA やコメントの中にこの文字列がある正当な応答も、ページ全体が読めない応答になる。

## 根拠

- `src/xml/parse-xml.ts` の `parseXml`。再レビュー（2026-09-27）で、先頭だけを正規表現で見る書き方は、処理命令を挟むと見逃し、コメントを並べた応答で処理時間が指数的に増えると分かり、文書全体から探す形に戻した。PORTERS が CDATA を返すかは確かめていない。

## 影響

🟢。エラーで止まる側に倒れる。値に "<!DOCTYPE" を含むレコードがあると、そのページが読めない。

## 検出経緯

2026-09-27 の応答の読み方と日時の軽微な指摘の修正（fix/xml-util-low-review）を、change-review の手順でレビューし直したときに見つけた。止めどきの規則により、この回では直さずに記録する。

## 推奨

- 最初のルート要素より前の部分から、コメント・処理命令を取り除いてから探す（時間が長さに比例する書き方で）。
- 止めどきの規則（Low だけになったら直さずに記録する）により、この回では直さずに記録する。

## 処置

**対応しない（2026-09-27・fix/review-followup-low・`396b9eb`）。** 文書全体から `<!DOCTYPE` を探す今の形を残す。先頭だけを見る書き方は、処理命令を挟むと見逃し、コメントを並べた応答で処理時間が指数的に増えると分かった（RV-108 の再レビュー）。値の中に同じ文字列がある応答はエラーで止まる側に倒れ、PORTERS が CDATA を返す例は reference に無い。

# RV-156 🟢 2xx でない応答に項目ごとの結果が載っていると、一括書き込みはその内訳を捨てる

- 重要度: 🟢 ／ 観点: フェイルセーフ
- 状態: wontfix

## 概要

一括書き込みの応答が 2xx でなく、本文に項目ごとの結果（`<Item><Code>101</Code>…`）が載っていると、`code: 0` の 1 つのエラーになり、項目ごとの結果は利用者に返らない。ルート要素の名前が合えば、項目の無い本文（`<Candidate><Foo/></Candidate>`）も成功の本文として読まれる。

## 根拠

- `src/http/read-response.ts`、`src/xml/parse-write-result.ts`。実行して確認済み（再レビュー・2026-09-27）。

## 影響

🟢。そのバッチは「書き込まれた可能性がある」として安全側に倒れる。内訳が分からないので、利用者は読み直して確かめる必要がある。

## 検出経緯

2026-09-27 の RV-153・RV-154 の修正（fix/rv-153-154）を、change-review の手順でレビューし直したときに見つけた。止めどきの規則により、この回では直さずに記録する。

## 推奨

- 2xx でない応答でも項目ごとの結果を返すか、今のまま結果が分からないとするかを決める（LV-9 の実機確認と合わせる）。
- 止めどきの規則（Low だけになったら直さずに記録する）により、この回では直さずに記録する。

## 処置

**対応しない（2026-09-27・fix/rv-155-156）。** 実機の PORTERS が 2xx 以外の応答に項目ごとの結果を載せるかは分かっていない（reference は成功の形しか書いていない）。載らないなら、項目ごとの結果を読む仕組みは使われないコードになる。今の形は、そのバッチを「書き込まれた可能性がある」として止まる側に倒れ、利用者には読み直して確かめるよう案内する。LV-9 の「関連」に、2xx 以外の応答に PORTERS の本文が載るかを記録し、載るなら見直すと書き足した。

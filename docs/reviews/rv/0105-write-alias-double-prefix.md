# RV-105 🟢 書き込みで、接頭辞付きの alias に接頭辞をもう一度付ける

- 重要度: 🟢 ／ 観点: API 忠実性

## 概要

`"Person.P_Name"` を書き込むと `<Person.Person.P_Name>` になる。読み込みでは接頭辞を外すので、扱いが揃っていない。

- 実測（サブエージェント）。

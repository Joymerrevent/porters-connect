# RV-148 🟢 0000 年の日付と日時は、読めるのに書けない

- 重要度: 🟢 ／ 観点: 一貫性
- 状態: open

## 概要

`"0000/01/01"` は `"0000-01-01"` として読めるが、書き込みは 0001〜9999 年だけなので、読んだ値をそのまま書き戻すと拒否される。

## 根拠

- `src/util/datetime.ts` の `portersDateToIso` / `portersDateTimeToIso` と `isoToPortersDate`。実測（再レビュー・2026-09-27）。

## 影響

🟢。PORTERS が 0000 年を返すことはまず無い。

## 検出経緯

2026-09-27 の応答の読み方と日時の軽微な指摘の修正（fix/xml-util-low-review）を、change-review の手順でレビューし直したときに見つけた。止めどきの規則により、この回では直さずに記録する。

## 推奨

- 読み込みでも 0000 年を拒否するか、書き込みで受けるかをそろえる。
- 止めどきの規則（Low だけになったら直さずに記録する）により、この回では直さずに記録する。

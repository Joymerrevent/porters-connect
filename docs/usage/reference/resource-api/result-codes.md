# リソース Result Code（認証エラーとは別系統）

Resource API が返す Result Code の一覧と、ライブラリがそれを再試行するかどうかを引くページです。

出典: <https://hrbcapi.porters.jp/hc/ja/articles/115008171708-Result-Code-List>（updated_at 2026-07-16、取得 2026-06-12・2026-09-20 に差分反映）。
全体像は [Resource API 概要][readme]。

下の番号は Resource API（Read / Write）のもので、**認証 API のエラー（[認証エラー][errors]）とは
番号体系が異なる**ので混同しない（番号が重複しても意味が違う）。

**`<Code>` がどこに出るかは Read と Write で違う**（[write-format][write-format] のレスポンス節）。

|           | 成功                                                                  | エラー                                                   |
| --------- | --------------------------------------------------------------------- | -------------------------------------------------------- |
| **Read**  | HTTP 200 ＋ ルート `<{Resource}>` 直下の `<Code>0`                    | HTTP 200 以外、またはルートの `<Code>` が 0 以外         |
| **Write** | HTTP 200 ＋ **`<Item>` ごと**の `<Code>0`（ルートに `<Code>` は無い） | HTTP 200 以外、または該当 `<Item>` の `<Code>` が 0 以外 |

**Write がリクエストごと拒否されたときの形は出典に書かれていない。** ライブラリはルートの
`<Code>` があればそれを読む<!-- 根拠: ADR-0045 -->が、その形で返るかどうかは実機で未確認<!-- 根拠: LV-11 -->。

| Code      | 意味                                                                                   | ライブラリが再試行するか                                       |
| --------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 0         | 成功                                                                                   | —                                                              |
| 5         | ユーザー ID 無効                                                                       | しない（設定の誤り）                                           |
| 6         | ユーザーに権限なし                                                                     | しない（権限の不足）                                           |
| 7         | Resource が存在しない                                                                  | しない                                                         |
| 8         | 内部エラー（制御コード混入 / and 複数 ID）                                             | しない（入力の誤り）                                           |
| 9         | 一時利用不可・メンテ（GAS / Cloudflare Workers、**`x-forwarded-for` ヘッダ**でも出る） | する（待ってから）。`x-forwarded-for` ヘッダが原因なら、しない |
| 100       | パラメータが無効                                                                       | しない（入力の誤り）                                           |
| 101       | 必須パラメータ不足（Token 未反映など）                                                 | しない（または認証の不備）                                     |
| 102       | パラメータが多すぎ                                                                     | しない（入力の誤り）                                           |
| 103       | パラメータ値が無効（Content-Type/version/日時/Option など）                            | しない（入力の誤り）                                           |
| 104〜116  | 値の書式・型・範囲エラー                                                               | しない（入力の誤り）                                           |
| 124       | 範囲超過（itemstate と、91 日以上前の UpdateDate）                                     | しない（入力の誤り）                                           |
| 126 / 127 | Phase 関連エラー                                                                       | しない（入力の誤り）                                           |
| 133       | itemstate 値が無効                                                                     | しない（入力の誤り）                                           |
| 146       | version 値が無効                                                                       | しない（入力の誤り）                                           |
| 301       | データが既に存在（重複 Process など）                                                  | しない（重複）                                                 |
| 302       | トランザクションエラー / 対象削除済み                                                  | する                                                           |
| 303       | 子要素が存在                                                                           | しない                                                         |
| 304       | 他要素から参照されている                                                               | しない                                                         |
| 400       | データへの権限なし/不足                                                                | しない（権限の不足）                                           |
| 401       | **Access Token 期限切れ**                                                              | する（Refresh してから）                                       |
| 402       | **Access Token 無効**                                                                  | する（トークンを取り直してから）                               |
| 403       | データ権限なし（権限付与未実施/スコープ不足）                                          | しない（権限付与が要る）                                       |
| 404       | partition が存在しない/利用期間外（未開始/解約/ID 誤り/Token 失効）                    | 状況による                                                     |
| 406       | IP アドレス制限                                                                        | しない（IP アドレスの申請が要る）                              |
| 500       | 登録最大件数超過                                                                       | しない                                                         |
| 601       | アプリ権限不足                                                                         | しない（PORTERS への申請が要る）                               |
| 1000      | 処理失敗                                                                               | 状況による                                                     |

エラーモデル（ライブラリの `PortersError`）への対応と症状別の対処は [エラーと再試行][guide] を参照。

# リソース Result Code（認証エラーとは別系統）

出典: <https://hrbcapi.porters.jp/hc/ja/articles/115008171708-Result-Code-List>（updated_at 2026-07-16、取得 2026-06-12・2026-09-20 に差分反映）。
全体像は [Resource API 概要][readme]。

下の番号は Resource API（Read / Write）のもので、**認証 API のエラー（[認証エラー][errors]）とは
番号体系が異なる**ので混同しない（番号が重複しても意味が違う）。

**`<Code>` がどこに出るかは Read と Write で違う**（[write-format][write-format] のレスポンス節）。

|           | 成功                                                                  | エラー                                                   |
| --------- | --------------------------------------------------------------------- | -------------------------------------------------------- |
| **Read**  | HTTP 200 ＋ ルート `<{Resource}>` 直下の `<Code>0`                    | HTTP 200 以外、またはルートの `<Code>` が 0 以外         |
| **Write** | HTTP 200 ＋ **`<Item>` ごと**の `<Code>0`（ルートに `<Code>` は無い） | HTTP 200 以外、または該当 `<Item>` の `<Code>` が 0 以外 |

**Write がリクエストごと拒否されたときの形は出典に書かれていない。** ライブラリはルートの
`<Code>` があればそれを読む（[ADR-0045][adr45]）が、その形で返るかどうかは実機で未確認
（[live-verification][lv] LV-11）。

| Code      | 意味                                                                                   | リトライ方針（本ライブラリ案）               |
| --------- | -------------------------------------------------------------------------------------- | -------------------------------------------- |
| 0         | 成功                                                                                   | —                                            |
| 5         | ユーザー ID 無効                                                                       | 不可（設定）                                 |
| 6         | ユーザーに権限なし                                                                     | 不可（権限）                                 |
| 7         | Resource が存在しない                                                                  | 不可                                         |
| 8         | 内部エラー（制御コード混入 / and 複数 ID）                                             | 不可（入力）                                 |
| 9         | 一時利用不可・メンテ（GAS / Cloudflare Workers、**`x-forwarded-for` ヘッダ**でも出る） | 可（バックオフ）。ヘッダ起因なら不可（除外） |
| 100       | パラメータが無効                                                                       | 不可（入力）                                 |
| 101       | 必須パラメータ不足（Token 未反映など）                                                 | 不可（or 認証）                              |
| 102       | パラメータが多すぎ                                                                     | 不可（入力）                                 |
| 103       | パラメータ値が無効（Content-Type/version/日時/Option など）                            | 不可（入力）                                 |
| 104〜116  | 値の書式・型・範囲エラー                                                               | 不可（入力）                                 |
| 124       | 範囲超過（itemstate と 91 日以前の UpdateDate）                                        | 不可（入力）                                 |
| 126 / 127 | Phase 関連エラー                                                                       | 不可（入力）                                 |
| 133       | itemstate 値が無効                                                                     | 不可（入力）                                 |
| 146       | version 値が無効                                                                       | 不可（入力）                                 |
| 301       | データが既に存在（重複 Process など）                                                  | 不可（競合）                                 |
| 302       | トランザクションエラー / 対象削除済み                                                  | 可（再試行）                                 |
| 303       | 子要素が存在                                                                           | 不可                                         |
| 304       | 他要素から参照されている                                                               | 不可                                         |
| 400       | データへの権限なし/不足                                                                | 不可（権限）                                 |
| 401       | **Access Token 期限切れ**                                                              | 可（Refresh 後）                             |
| 402       | **Access Token 無効**                                                                  | 可（再取得後）                               |
| 403       | データ権限なし（権限付与未実施/スコープ不足）                                          | 不可（要権限付与）                           |
| 404       | partition が存在しない/利用期間外（未開始/解約/ID 誤り/Token 失効）                    | 状況次第                                     |
| 406       | IP アドレス制限                                                                        | 不可（申請）                                 |
| 500       | 登録最大件数超過                                                                       | 不可                                         |
| 601       | アプリ権限不足                                                                         | 不可（要申請）                               |
| 1000      | 処理失敗                                                                               | 状況次第                                     |

エラーモデル（ライブラリの `PortersError`）への対応は ADR-0006 を参照。
利用者向けの症状別対処は [エラーハンドリング ガイド][guide] を参照。

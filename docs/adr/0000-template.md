## 信じている入力

この決定によって**外部から受け取り、正しいと信じることになる値**を実装前に洗い出す。
該当が無ければ「該当なし — <理由>」と 1 行書く。**節ごと消さない**（空欄だと「無かった」のか
「書き忘れた」のか区別が付かない）。

**必ず書く目安**: 信頼できない入力源（外部 API・LLM の出力・人が編集できる文書・イベント
ペイロード・環境設定）が **3 つ以上**あるとき。3 つ揃った時点で、支配的な故障は
「**取れなかったものを、取れたと読む**」に決まる。

| 値         | 出どころ                | 誰が書けるか       | 取れなかったら | 誤っていたら                 |
| ---------- | ----------------------- | ------------------ | -------------- | ---------------------------- |
| <値の種類> | <API / LLM / 人 / 設定> | <第三者が書けるか> | <安全側の既定> | <何と突き合わせて検出するか> |

- **取れなかったら** — 空・取得失敗・読めない を「該当なし＝問題なし」と読まない形を先に決める。
  **取得失敗と 0 件は別の状態**として扱えるか。迷ったら「気づける方」に倒す。
- **誤っていたら** — **形式の検証と、事実との突き合わせは別物**。正規表現を通っただけの値は
  「読める形をしている」ことしか保証しない。何と突き合わせるかをここで決めておく。

粒度は実装の変数ではなく**値の種類**（10 行程度に収まる）。実装後のレビューで
1 行 = 1 変数へ展開する（`.claude/skills/change-review` の入力棚卸し）。

<!--
  **「見送り」と判定した PR をここへ書かない。** この行が取り込む順そのもの。

  番号に head SHA を添えるのは、承認したのが「その PR」ではなく「その PR のその
  コミット」だから。レポートを書いた後に dependabot が force-push すると、誰も
  CHANGELOG を読んでいないコミットが「承認済み」として取り込まれうる。取り込む前に
  この SHA が現 head の祖先かを確かめる（SKILL.md §5）。

  順序の根拠はこの下に散文で書く — 競合しないものから、影響の重いもの（prod 依存）は
  単独で入れて develop の緑をその変更に帰属させる、どの PR がどのファイルで競合するか。
  ここに `#223 は見送り` のように番号を書いても、取り込む対象にはしない。

公開 API リファレンスの日本語を英語に直し、CI が `engines` の下限そのものを走らせるようにしました（RV-51 / RV-53）。**公開 API の変更はありません。**

- **リファレンスの日本語**（RV-51）— 187 頁のうち 4 頁に日本語が残っていました。
  出どころの JSDoc を直し、以後の混入は `pnpm check:api` が検出します。
  公開サーフェスの JSDoc は英語、README とガイドは日本語ファースト、という切り分けは変わりません。
- **`engines` の下限**（RV-53）— `engines.node` は `>=22.12.0` を約束していますが、
  CI のマトリクスは `22`（その時点の 22 系最新に解決される）だったため、
  **22.12.0 そのものは一度も走っていませんでした**。マトリクスに下限を足し、
  ずれは `pnpm check:release` が検出します。

Node 22.12.0 で動かしている場合、そのバージョンが CI で実際に検証されるようになりました。

内部の検査を 1 本増やしました（`pnpm check:lv`・RV-50 / RV-52）。**公開 API の変更はありません。**

契約後に実機確認する仮定（`docs/live-verification.md` の LV）と、コード側の `VERIFY(live)`
コメントの対応を**双方向**で検査します。実測では両方向で崩れており、とくに
**コードに仮定があるのに一覧に無い**もの（＝契約後の確認リストに乗らない）が 3 件ありました。
その 3 件は LV-27〜29 として起票済みです。

利用者への影響はありませんが、このライブラリが「PORTERS の実挙動のうち、まだ実機で
確かめていないこと」を取りこぼさない仕組みを持つようになった、という位置づけです。
